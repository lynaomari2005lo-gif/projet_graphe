# Projet Graphe

Ce dépôt contient mon projet de graphe réalisé dans le cadre de mes études.

## À propos

Ce projet consiste à représenter et manipuler des structures de données complexes sous forme de graphes.  
Il peut inclure :

- la création de nœuds et d’arêtes
- l’affichage du graphe
- des algorithmes de parcours et de recherche
